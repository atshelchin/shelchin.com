简单描述一下这个项目

**网站看到的你的 IP。**

很多网站会按 IP 所在国家限制访问，但开了 VPN 不一定真换成功。打开 ip111.xyz 看一眼：显示的是 VPN 的国家就没问题，还是自己的国家就说明没切过去。

网站：https://ip111.xyz/

## 显示什么

- 公网 IP（IPv4 或 IPv6）
- 国家、地区、城市
- ASN 和运营商名称
- 处理这次请求的 Cloudflare 节点（colo，比如 `LAX`）
- HTTP 协议和 TLS 版本
- 可以一键重新查询，也可以查看原始 JSON 数据

## 终端里用

```sh
curl ip111.xyz        # 纯文本
curl ip111.xyz/ip     # 只返回 IP
curl ip111.xyz/json   # JSON
```

`/json` 返回的样子：

```json
{
  "ip": "2607:8700:5500:c51d::2",
  "family": "v6",
  "country": "US",
  "region": "California",
  "city": "Los Angeles",
  "asn": 25820,
  "as_org": "IT7 Networks Inc",
  "colo": "LAX",
  "http_protocol": "HTTP/1.1",
  "tls_version": "TLSv1.3",
  "ts": "…"
}
```
